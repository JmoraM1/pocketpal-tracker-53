# My Lovable Wallet

Necesito crear un control de flujos de mis gastos de finanzas, en donde tendré el concepto de sueldo, plan celular, recibos casa, cuota crédito Banco de Bogotá, cadena Tele treinta días, tarjeta, gasolina, bolsillo de Cami y Juan, bolsillo de emergencia, bolsillo moto mantenimiento, vale de abono extra, crédito. Donde tendré el monto, la descripción, si ya lo pagué o no lo pagué, mi total de gastos y mi disponible de ahorro. Necesito que lo crees con botones, eh, de fácil movimiento, que se puedan editar fácilmente todo lo que le indico y me dé un visual o un panel de cómo voy, si tengo muchos gastos o muchas deudas.
